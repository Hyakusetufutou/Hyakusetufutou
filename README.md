## Featured Projects

### 📱 かけログ — 家計簿アプリ

SwiftUIを使用して開発したiOS向けの家計簿アプリです。

- 収入・支出の記録、カテゴリ管理
- カレンダー・グラフによる収支の可視化
- 検索、バックアップ・復元、アプリロック
- MVVMをベースとした設計

**Tech Stack:** Swift / SwiftUI / Core Data / Combine
